# Notes

Findings and tips from using the skills and tools.

## Models

- 2026-11-08: GPT Luna Max (870k context window) does well at `book-memory-extraction`.
- 2026-11-08: Asking an agent after completing a skill for feedback works nicely.
- 2026-11-08: You can change API anytime you want when designing tools for agents, nice feature.
- 2026-11-08: When testing tool for agents you can ask an orchestrator agent to create tests for you to test new and old tool agains multiple agents to see how they deal with it.
## Images

- 2026-11-08: If an image from ChatGPT has artifacts, rerun the exact same prompt. The output varies enough between runs that a rerun can come out clean.
